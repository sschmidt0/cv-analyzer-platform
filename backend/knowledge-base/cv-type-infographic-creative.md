# CV Infográfico y CV Creativo

## Para quién es ideal

- Perfiles profesionales **creativos** (diseño, comunicación, marketing, arte).
- Personas que quieren **diferenciarse** del resto de candidatos.
- Quienes pueden mostrar con el propio CV un **ejemplo de sus habilidades**.

## Características principales

- El CV en sí mismo es un **ejemplo de creatividad** y un producto por sí solo.
- Se prioriza la imagen, los esquemas y los iconos sobre el texto.
- Se aleja de estructuras tradicionales (cronológica, bloques estándar).
- La innovación está en el **formato de presentación**.

## Subtipos

| Subtipo | Descripción |
|---|---|
| **Infografía** | Datos visualizados con gráficos, iconos y esquemas |
| **Videocurrículum** | Presentación en vídeo (herramientas: Canva, CapCut, VideoScribe) |
| **CV interactivo** | PDF o web con elementos interactivos |
| **CV web / portafolio** | Página web personal (WordPress, Wix, Carrd) |
| **CV en formato cómic** | Narración visual de la trayectoria |

## Cómo crearlo

1. Utiliza un programa de edición (Adobe Illustrator, Canva, Figma) o herramientas online con plantillas.
2. Elige la plantilla más adecuada a la información que quieres mostrar.
3. Prioriza imagen, esquemas e iconos; reduce el texto al mínimo.
4. No sigas la estructura estándar de bloques.
5. Asegúrate de que se puede **imprimir en A4** sin perder el formato.

## Herramientas recomendadas

- Canva, ResumeMaker, VisualCV, CurriculumYa, NovoResume, CVDesignR
- Para portafolios: Behance, Dribbble, Carbonmade

## Advertencias

- Muchos sistemas ATS (de filtrado automático de CVs) no leen bien el texto de PDFs con diseño complejo.
- Siempre tener una **versión en A4** lista para imprimir para las entrevistas.
- No abusar del color: máximo dos colores que contrasten bien.
