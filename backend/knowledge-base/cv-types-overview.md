# Tipos de CV: cuándo usar cada modelo

Existen varios modelos de CV. La elección depende de la trayectoria profesional, el objetivo laboral y lo que se quiera destacar. No hay un modelo único: se puede adaptar y combinar.

## Resumen comparativo

| Tipo | Cuándo usarlo | Qué destaca |
|---|---|---|
| **Cronológico inverso** | Primera vez, carrera progresiva | Progresión temporal |
| **Funcional** | Experiencia diversa, reorientación | Habilidades y funciones |
| **Temático** | Dominio de un sector, reorientación | Áreas de trabajo |
| **Competencial** | Cambio profesional, compensar falta de experiencia | Competencias clave |
| **Infográfico / Creativo** | Perfiles creativos, diferenciación | Diseño y presentación visual |
| **Combinado o mixto** | Gran trayectoria formativa y profesional | Habilidades + experiencia + formación |
| **Europass** | Búsqueda de empleo en la Unión Europea | Formato estandarizado europeo |

## Tipos especiales de formato

- **Videocurrículum**: presentación en vídeo de la trayectoria. Herramientas: Canva, CapCut, VideoScribe.
- **CV web / portafolio**: página web personal. Plataformas: WordPress, Wix, Carrd.
- **Presentación dinámica**: Prezi, PowerPoint, Genial.ly.
- **Portafolio digital**: colección de trabajos. Recomendado en arte y diseño. Plataformas: Behance, Dribbble, Carbonmade.

## Regla general

> El orden de los bloques se puede cambiar según lo que interese destacar. Si quieres destacar la experiencia, ponla antes que la formación.
